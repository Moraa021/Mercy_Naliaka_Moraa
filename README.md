# Portfolio — Mercy Naliaka Moraa

Personal portfolio website built with **React 19**, **Vite**, and **Tailwind CSS v4**, showcasing projects, technical skills, and systems engineering background.

Live Site: [Mercy Moraa](https://mercy-moraa.onrender.com) *(or your deployed link)*

---

## Technical Stack

* **Framework:** React 19 + Vite
* **Styling:** Tailwind CSS v4
* **Typography:** Fraunces, IBM Plex Mono, Plus Jakarta Sans
* **Deployment:** Vercel / Netlify / GitHub Pages

---

## Features & Highlights

* **Data-Driven Architecture:** All portfolio content, projects, and metadata are centralized in `src/data.js` for easy updates.
* **Component-Based Structure:** Modular React components for section maintenance (`src/components/`).
* **Responsive Layout:** Edge-to-edge container scaling (up to 1440px) with dedicated desktop navigation and mobile drawer menu.
* **SEO & Social Optimization:** Pre-configured meta tags, Twitter card previews, and Open Graph parameters in `index.html`.
